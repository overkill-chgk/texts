# Шкала знаний

## Описание

Шкала предназначена для приблизительной оценки уровня знаний, которые критически необходимы для нахождения ответа на вопрос.

Оценивается распространённость знания среди взрослых, хорошо образованных людей, не вовлечённых или мало вовлечённых в движение и не считающихся особо эрудированными. Чем выше балл, тем выше энциклопедическая сложность вопроса, редкость необходимового знания. Если некое знание получило широкое распространение среди игроков благодаря множеству вопросов на эту тему (например, «тест Бекдел»), его оценка не становится из-за этого ниже; редкость знания определяется для людей без большого опыта игры.

Оценка делается для одного человека (команды из одного игрока).

Если для нахождения ответа на вопрос требуется нескольких знаний, то вопрос получает наибольший балл из всех знаний. Балл может быть повышен, если максимальную оценку получили два и более необходимых для взятия знания. Как правило, повышение оценки требуется для высоких значений: два знания по 8 баллов, особенно из разных областей, дадут оценку 9, тогда как несколько знаний по 3 балла оставят общую оценку 3. Для вопросов, которые будут отыгрываться парами или тройками, уместно поднимать балл, если требуется несколько знаний уровня 5 и 6.

В случае тематического турнира можно грубо считать, что оценка сложности для знаний из соответствующей области снижается на 2 — ожидается, что почти все игроки являются любителями данной области. Аналогично можно оценивать знания, особенно распространённые в регионе проведения турнира.

Области знания — это довольно обширные сущности, например, конкретный вид спорта (хоккей, автоспорт, лёгкая атлетика), вид искусства (кино, живопись, архитектура), область науки (биология, история, социология). Область у́же, чем направление — спорт, искусство, наука, — но шире, чем специализация — история ЧМ по хоккею, ралли-рейды, нуар в кино, импрессионизм, генетика, история США.

Все предложенные референсы (распространённость среди разных категорий людей, оценка уместности для вопросов своей игры, примеры) являются приблизительными и могут давать разные значения сложности для разных знаний. В частности, сильный дисбаланс возникает для любых немедийных знаний, а также для узких областей: вполне может получиться 8 для обычных людей и 5 для интересующихся любителей). Приоритет имеет колонка с оценкой распространённости знания среди обычных людей, без интереса к конкретной теме.

В асимметричных случаях под наличием знания предполагается, что вспоминается сущность по описанию («известен тем-то, кто это?»), а не наоборот («чем известен такой-то?»).

Число градаций шкалы — от 0 до 10 — выбрано для удобства оценки. Баллы шкалы не задуманы как сопоставимые с баллами сложности турнирных пакетов.

## Применение

После простановки баллов вопросам их можно использовать для следующих задач.

- Расстановка вопросов внутри тура или в пакете в соответствии с представлениями редактора.
- Для наиболее требовательных к знаниям вопросов — анализ, соответствуют ли они концепции пакета или требованиям оргкомитета.
- Для вопросов, получивших высокий балл, — проверка, превосходит ли логическая сложность вопроса его энциклопедическую сложность. Таким пороговым значением может ориентировочно быть:
  - 5 баллов и выше — для начинающей аудитории и для игр в парах или тройках;
  - 6 баллов и выше — для массовых турниров;
  - 7 баллов и выше — для опытных команд.
