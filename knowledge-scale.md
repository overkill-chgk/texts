# Шкала знаний

Шкала предназначена для приблизительной оценки уровня знаний, критически необходимых для нахождения ответа на вопрос.

Оценивается распространённость знания для взрослого, хорошо образованного человека, не вовлечённого или мало вовлечённого в движение и не считающегося особо эрудированным. Если некое знание получило широкое распространение благодаря множеству вопросов на эту тему (например, «тест Бэкдел»), оно не получает из-за этого более низкую оценку. Иными словами, оценка сложности даётся сверху (не ниже *n*), для людей без большого опыта игры.

Оценка даётся для одного человека (команды из одного игрока).

Предполагается, что вопрос в целом оценивается по максимальному значению для каждого из требуемых знаний. Если два необходимых для взятия знания имеют максимальную оценку, вопрос в целом может быть оценен на балл выше, если три и более — должен быть оценен на балл выше. Например, если в вопросе нужны три знания со значением 6, а остальные знания имеют оценку не выше 5, то оценка сложности знаний для вопроса будет 7.

За скобки выносятся региональная специфика — знания, особенно распространённые в отдельном регионе. В случае тематического турнира можно грубо считать, что оценка сложности снижается на 2 для соответствующей области — любители рассматриваются как обычные игроки.

Области знания — это довольно широкие области, например, конкретный вид спорта (хоккей, автоспорт, лёгкая атлетика), вид искусства (кино, живопись, архитектура), область науки (биология, история, социология). У́же, чем направления — спорт, искусство, наука, — но шире, чем специализация — история ЧМ по хоккею, ралли-рейды, нуар в кино, импрессионизм, генетика, история США.

Все предложенные оценки — распространённость среди разных категорий людей, оценка уместности для вопросов своей игры, примеры — являются приблизительными и могут давать разные значения сложности для разных знаний. В частности, сильный дисбаланс возникает для любых немедийных знаний и для узких областей (может получиться 8 по оценке для обычных людей и 5 для интересующихся). Приоритет имеет колонка с оценкой распространённости знания среди обычных людей, без интереса к конкретной теме. Во всех случаях под наличием знания предполагается, что вспоминается сущность по описанию (известен тем-то, кто это?), а не наоборот (чем известен такой-то?).

Число градаций шкалы — от 0 до 10 — выбрано для удобства оценки. Баллы шкалы не задуманы как сопоставимые с баллами сложности турнирных пакетов.
